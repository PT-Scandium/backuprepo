backuprepo (bb) — Windows setup

Install, log in, and upload files & folders to Backblaze B2 — native B2 backend, v1.0.6

You have downloaded bb-v1.0.6-windows-amd64.exe from the GitHub releases page. Follow the 16 steps below in order.

1 · Set up the environment

#StepExactly what to do
1Open File Explorer Click the yellow folder icon on the taskbar (or press Windows+E). In the left sidebar, click Downloads — you should see bb-v1.0.6-windows-amd64.exe in the list.
2Turn on file name extensions In the Explorer toolbar click View → Show → tick File name extensions. (Windows 10: the View tab → tick File name extensions.) Without this, step 4 accidentally names the file bb.exe.exe.
3Unblock the download Right-click the file → Properties → stay on the General tab → at the very bottom tick Unblock → click OK. (If there is no Unblock box, Windows already trusts it — just click Cancel.)
4Rename it to bb.exe Left-click the file once to select it, then press F2. Type bb.exe and press Enter. When Windows asks “the file might become unusable”, click Yes.
5Create a folder and move it there In the sidebar click Home (Windows 10: This PC → Local Disk (C:) → Users → your name). Right-click any empty space → New → Folder → name it bb → Enter. Now go back to Downloads, drag bb.exe onto that new bb folder in the sidebar to move it in.
6Tell Windows where to find it Press Windows, type environment, and click Edit environment variables for your account. In the upper box, click the row named Path → Edit… → New → type C:\Users\<your-name>\bb → OK → OK. (Use your real Windows user folder name — it is shown in the Explorer address bar from step 5.)
7Check that it works Press Windows → type powershell → Enter. Type bb version → Enter. It should print bb 1.0.6. (If you already had a PowerShell window open, close it and open a new one — step 6 only applies to new windows.)
SmartScreen warning? The binary is unsigned, so Windows may show “Windows protected your PC” on first run — click More info → Run anyway. Also: bb.exe is a console program. Double-clicking it just runs bb status and closes the window, so always run it from PowerShell.

2 · Log in (one time only)

#StepExactly what to do
8Start setupbb init
9Credential promptsPaste keyID → Enter, paste applicationKey → Enter, type bucket name → Enter
10Bucket IDResolved automatically. If it still asks, paste the Bucket ID from the B2 console → Enter
11Skip the two S3 promptsPress Enter on S3 endpoint URL, then Enter again on S3 region — bb init then selects the B2 backend for you
12Folder to watchPress Enter to skip — you can add one later with bb watch
13Check the B2 backendbb backend → b2 (set automatically by step 11 since v1.0.5; on older versions run bb backend b2)
14Verify the loginbb ls — lists your bucket

Credentials are saved encrypted in %USERPROFILE%\backup_repo\. You never log in again unless the key is rotated or revoked.

3 · Upload a file or a folder

#StepExactly what to do
15Upload one filebb put C:\Users\you\Documents\report.pdf reports/report.pdf
16Upload a whole folderbb put C:\Users\you\Documents\ documents/ -r

Confirm everything arrived with bb ls -r. If a big folder upload is interrupted, resume it cheaply — already-uploaded files are skipped:

bb put C:\Users\you\Documents\ documents/ -r --skip-existing

Optional · Automatic backup

Instead of running bb put by hand, register a folder once and let bb send only what changed. bb upload is a safe no-op when nothing has changed:

bb watch C:\Users\you\Documents
bb upload

To keep it running continuously, create a scheduled task that starts the watcher at every logon:

schtasks /create /tn "backuprepo" /sc onlogon /tr "$env:USERPROFILE\bb\bb.exe start" /f

Stop the watcher at any time with bb stop.
